# RNG 过场动画格式

`RNG.MKF` 保存 320×200、8 位索引色的增量动画。颜色来自当前 palette；动画数据本身
只修改索引 framebuffer，不负责索引到 RGBA 的转换。

## 双层索引

外层是普通 MKF，每个 chunk 对应一段动画。动画 chunk 内又有一张小端 `u32` offset
表：第一个 offset 同时是表长和第 0 帧起点，相邻 offset 定义一帧。首 offset 必须至少
为 8、能被 4 整除且不超过动画 chunk；所有 offset 必须单调且位于 chunk 内。帧编号和
动画编号均从 0 开始。

offset 表允许相邻边界相同，由此产生的空帧没有可播放内容；播放端应停止或跳过，不能把它
传给 YJ_1 解压器。

每个帧 chunk 是一条 YJ_1 流。解压结果不是完整图片，而是对上一帧的增量命令。播放第一
帧前 framebuffer 清零，此后每帧原地更新同一个 64000 字节缓冲区。

## 增量命令

目标游标按行优先遍历 320×200 framebuffer。所有长度均以“双像素”为单位。

| opcode | 操作 |
|---|---|
| `00`, `13` | 结束当前帧 |
| `02` | 跳过 1 对像素 |
| `03 n` | 跳过 `n + 1` 对像素 |
| `04 lo hi` | 跳过 `u16 + 1` 对像素 |
| `06..0A` | 写入 opcode 对应的 1..5 对 literal 像素 |
| `0B n` | 写入 `n + 1` 对 literal 像素 |
| `0C lo hi` | 写入 `u16 + 1` 对 literal 像素 |
| `0D..10 a b` | 将像素对 `(a,b)` 重复 2..5 次 |
| `11 n a b` | 将像素对重复 `n + 1` 次 |
| `12 lo hi a b` | 将像素对重复 `u16 + 1` 次 |

“跳过”表示保留上一帧像素。解析时必须同时检查命令源数据和目标 framebuffer 边界；未知
opcode、截断参数或任何越界操作均视为格式错误。

启动商标使用动画 6、调色板 3，从第 0 帧起按 25 fps 播放；offset 表中的首个空帧是
正常结束标记。最后一帧停留 1 秒，再用约 600ms 淡出并进入标题画面。
