# 脚本记录格式

## 存储

`SSS.MKF` chunk 4 是连续的脚本记录表。每条记录固定为 8 字节：

| 偏移 | 类型 | 字段 |
|---:|---|---|
| 0 | `u16` | opcode |
| 2 | `u16` | operand 0 |
| 4 | `u16` | operand 1 |
| 6 | `u16` | operand 2 |

所有字段均为 little-endian。场景和事件对象保存的脚本入口直接作为记录表索引，记录
0 通常作为空入口。解析器要求 chunk 非空且长度是 8 的整数倍；执行时仍需验证每个
入口和跳转目标没有越界。

## 当前运行时覆盖

最小触发脚本运行时目前实现以下 opcode：

| Opcode | 行为 |
|---:|---|
| `0x0000` | 结束脚本 |
| `0x0001` | 结束并将事件对象入口更新为下一条记录 |
| `0x0003` | 无条件跳转到 operand 0 |
| `0x0005` | 请求重绘；当前同步渲染管线中继续执行 |
| `0x0008` | 将事件对象入口更新为下一条记录并继续 |
| `0x0009` | 等待 operand 0 帧，0 按 1 帧处理 |
| `0x000B..0x000E` | 当前事件对象以速度 2 向指定方向走一步 |
| `0x000F` | 设置当前事件对象方向和/或帧 |
| `0x0013` | 设置事件对象绝对位置 |
| `0x0014` | 设置当前事件对象动作帧并面向南 |
| `0x0015` | 设置玩家方向和动作帧 |
| `0x0016` | 设置指定事件对象方向和动作帧 |
| `0x003B` | 后续消息使用居中对话位置 |
| `0x003C` | 后续消息使用上方对话位置 |
| `0x003D` | 后续消息使用下方对话位置 |
| `0x003E` | 后续消息使用居中窗口位置 |
| `0x0047` | 播放音效；音频后端接入前识别并继续 |
| `0x0043` | 设置场景音乐；音频后端接入前识别并继续 |
| `0x0045` | 设置战斗音乐；战斗系统接入前识别并继续 |
| `0x0049` | 设置事件对象状态 |
| `0x0046` | 将队伍放到 operand 0/1/2 指定的地图 tile |
| `0x0050` | 淡出画面；过渡效果接入前识别并继续 |
| `0x006C` | 按偏移移动事件对象并推进动画 |
| `0x006E` | 按偏移移动玩家并更新相机 |
| `0x0065` | 设置主角场景精灵；非主角槽位暂时识别并继续 |
| `0x0070` | 将队伍移动到指定 tile；当前直接完成移动 |
| `0x0075` | 设置队伍成员；单角色 M2 运行时识别并继续 |
| `0x008E` | 恢复画面；当前同步渲染管线中继续执行 |
| `0xFFFF` | 显示 operand 0 指向的 `M.MSG` 消息并等待输入 |

执行器每次推进最多处理 1024 条非消息指令，以防损坏数据或跳转环导致主循环失去
响应。未实现的 opcode 会返回包含脚本入口和 opcode 的错误，不会静默跳过。
