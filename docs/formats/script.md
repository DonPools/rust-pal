# 脚本记录格式

## 存储

`SSS.MKF` chunk 4 是连续的脚本记录表。每条记录固定为 8 字节：

| 偏移 | 类型 | 字段 |
|---:|---|---|
| 0 | `u16` | opcode |
| 2 | `u16` | operand 0 |
| 4 | `u16` | operand 1 |
| 6 | `u16` | operand 2 |

所有字段均为 little-endian。场景和事件对象保存的脚本入口直接作为记录表索引，记录
0 通常作为空入口。解析器要求 chunk 非空且长度是 8 的整数倍；执行时仍需验证每个
入口和跳转目标没有越界。

## 当前运行时覆盖

最小触发脚本运行时目前实现以下 opcode：

| Opcode | 行为 |
|---:|---|
| `0x0000` | 结束脚本 |
| `0x0001` | 结束并将事件对象入口更新为下一条记录 |
| `0x0003` | 无条件跳转到 operand 0 |
| `0x0005` | 请求重绘；当前同步渲染管线中继续执行 |
| `0x0008` | 将事件对象入口更新为下一条记录并继续 |
| `0x003B` | 后续消息使用居中对话位置 |
| `0x003C` | 后续消息使用上方对话位置 |
| `0x003D` | 后续消息使用下方对话位置 |
| `0x003E` | 后续消息使用居中窗口位置 |
| `0x008E` | 恢复画面；当前同步渲染管线中继续执行 |
| `0xFFFF` | 显示 operand 0 指向的 `M.MSG` 消息并等待输入 |

执行器每次推进最多处理 1024 条非消息指令，以防损坏数据或跳转环导致主循环失去
响应。未实现的 opcode 会返回包含脚本入口和 opcode 的错误，不会静默跳过。
