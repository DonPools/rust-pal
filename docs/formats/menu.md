# 场景菜单行为

## 开场菜单

开场菜单使用 DOS 版 `FBP.MKF` 图片 60 作为背景，并循环播放 MIDI 31。一级菜单使用
`WORD.DAT` 词条 7、8，依次为新游戏和读取存档；菜单键在一级菜单等同选择新游戏。
选择读取后显示 1–5 槽，词条为 43–47，每槽右侧显示存档头中的四位保存次数。菜单键
返回一级菜单，并把默认选择恢复为新游戏。

确认新游戏后，场景 1 的进入脚本在黑屏期间启动，到第一次可见场景绘制时淡入。确认存档
后，从 `data/1.RPG`…`5.RPG` 或 `data/SAVES/1.rpg`…`5.rpg` 读取所选槽，恢复存档指定
场景、队伍、对象、调色板、波纹和音乐；加载存档不会重新执行该场景的进入脚本。空槽、
损坏存档或无法加载的场景会返回槽位菜单并重新淡入开场背景。

## 主菜单层级

场景中按菜单键先进入四项主菜单，词条使用 `WORD.DAT` 固定编号：

| 顺序 | 词条 ID | 行为 |
|---:|---:|---|
| 0 | 3 | 状态 |
| 1 | 4 | 仙术 |
| 2 | 5 | 物品 |
| 3 | 6 | 系统 |

主菜单使用上下或左右逐项选择，并在首尾循环。选择“物品”后还要经过“装备 / 使用”二项
菜单（词条 22、23），不能从场景菜单键直接进入物品列表。状态、仙术和物品操作结束后退出
整套主菜单；系统菜单可以在子菜单返回后继续停留于主菜单。

## 物品选择

DOS 中文版的 `WORD.DAT` 固定词条宽度为 10 字节，因此物品列表每行 3 项、每页 7 行。
导航规则不是循环选择：

- 左右移动一个背包槽位。
- 上下移动三个背包槽位。
- 越过首尾时夹紧到第一项或最后一项。
- 翻页起点以当前行向前四行为基准，并保持三项行对齐。
- 数量为 1 时不绘制数量，数量大于 1 时绘制青色两位数量。
- 不符合当前操作 flags 的物品仍然显示，但使用不可选颜色且确认无效。
- 物品菜单记住上次背包槽位；脚本消耗最后一件物品后将槽位夹紧到新列表末尾。

运行时背包必须按物品首次获得的槽位顺序保存，不能按对象 ID 排序。物品数量归零时删除该
槽位并压缩后续物品；再次获得同一物品时追加到末尾。版本 12 开发快照直接保存这一顺序。

## 场景使用物品

“使用”列表按 `kItemFlagUsable` 判断是否可选。`kItemFlagApplyToAll` 的物品直接以
`0xffff` 作为脚本 owner 执行，脚本结束后退出菜单。单体物品先进入队员选择，队员选择使用
上下或左右逐项移动并在首尾循环；执行完一次后继续停留在同一物品和队员上，允许连续使用。
物品耗尽时退回物品列表。

只有同时满足 `kItemFlagConsuming` 且脚本成功时才扣除一件物品。脚本执行失败时保持数量，
并继续允许选择目标。取消队员选择退回物品列表；取消物品列表退出整套场景菜单。

## 商店

买入列表沿用通用菜单规则，上下或左右逐项移动并在首尾循环。只有当前金钱不少于物品价格
时，确认物品才会继续打开“否 / 是”确认框。确认框默认选择“否”，菜单键等同于否；购买
成功后保持在原物品上，并用更新后的持有数量和金钱重绘。

卖出列表复用物品选择规则，只让包含 `kItemFlagSellable` 的物品可确认。卖出一件后保持在
卖出菜单；若该物品数量归零，则把选择位置夹紧到压缩后列表的新末尾。买卖确认均只在明确
选择“是”时修改状态。
