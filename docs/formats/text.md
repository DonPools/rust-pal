# 文本与字库格式

## 文本资源

- `WORD.DAT` 是固定 10 字节的 Big5 编码词条表，尾部空格和 NUL 不属于文本。
- `M.MSG` 连续保存 Big5 编码消息，不包含独立记录头。
- `SSS.MKF` chunk 3 是 little-endian `u32` 消息偏移表。消息 `n` 的范围为
  `offsets[n]..offsets[n + 1]`。

解析时要求词条文件长度是 10 的整数倍；消息偏移表至少包含两个偏移，长度是 4 的
整数倍，偏移单调不减且不能超过 `M.MSG` 长度。原版个别词条以 ASCII `1` 作为兼容
标记，读取时移除该尾字符。

## SDLPAL 补充说明

DOS 原版对象表没有物品描述字段。本地若存在可选的 `desc.dat`，则按 SDLPAL 补充格式
加载物品和法术说明；缺失或格式错误不影响原版资源启动。文件为 Big5 文本，每条有效记录
使用 `十六进制对象ID(名称)=说明`，说明中的 ASCII `*` 表示换行。标题、来源和空行不属于
记录。解析时验证对象 ID、Big5 双字节边界、重复 ID 和空说明，渲染时仍使用 PAL 位图字库。

## 位图字库

`WOR16.ASC` 是连续的双字节 Big5 字符码表。`WOR16.FON` 中对应字形从偏移
`0x682` 开始，每个字形占 30 字节，即 15 行、每行两个字节的 16x15 单色位图。
每行从高位到低位依次对应从左到右的像素。

加载器要求字符码表非空且长度为偶数，并验证字库包含所有码表项对应的 30 字节
记录。文本和字形在资源层保留 Big5 编码，桌面渲染层负责按 palette 颜色写入 RGBA
framebuffer。

## 对话布局与控制符

脚本 `0x003B..0x003E` 会设置后续消息的位置、palette 字色和可选的 `RGM.MKF`
头像编号。原版在 `320x200` 画面上的正文基准点如下：

| 位置 | 无头像正文 | 有头像正文 | 头像中心 |
|---|---:|---:|---:|
| 上方 | `(44, 26)` | `(96, 26)` | `(48, 55)` |
| 下方 | `(44, 126)` | `(20, 126)` | `(270, 144)` |
| 居中 | `(80, 40)` | - | - |
| 居中窗口 | `(160, 40)` | - | - |

文本系统初始化及 `PAL_EndDialog` 结束后均恢复为上方、默认字色、无头像布局。
上方和下方说话人标题分别从 y=8 和 y=108 开始；以冒号结尾的第一条消息作为标题，
不占正文行。每条 `0xFFFF` 消息固定占一行，原版不会根据可用宽度自动换行；正文行距为
18 像素，每页最多四行。连续 `0xFFFF` 消息会累计到当前页，页满时等待输入。下一条
脚本指令不是 `0xFFFF` 时，原版会先等待任意按键、清除当前对话，再执行该指令。因此
诸如 `WAIT` 的计时从对话确认之后才开始。

普通标题和正文以 `(x + 1, y)`、`(x, y + 1)`、`(x + 1, y + 1)` 三个方向绘制
黑色阴影。居中窗口使用 `DATA.MKF` 的 UI sprite 44–46 拼成单行框，默认正文为黑色且
不绘制文字阴影；其中 ASCII 数字使用黄色 UI 数字 sprite。居中窗口可由任意按键提前
关闭，并在约 1.4 秒后自动继续。每条居中窗口消息都会单独创建并删除窗口；若脚本紧接着
又输出一条消息而没有重新设置布局，下一条会恢复为上方、默认字色的普通对话。

消息中的 ASCII `-`、`'`、`@`、`"` 分别切换青、红、深红和黄字色；`$NN` 按原版
整数换算调整逐字延时，并持续影响后续消息。`~NN` 表示异步延时后结束当前文本，
`(`/`)` 选择 `DATA.MKF` chunk 12 中的三个等待图标，反斜杠转义下一个控制字符。
控制符本身不占普通文字的绘制宽度；原版计算居中窗口框宽时则按原始字符宽度把控制符也
计算在内。桌面播放状态按字符边界逐步揭示 Big5 正文；揭示期间按确认或取消只会显示完
当前页，随后才进入分页等待。进入等待后任意按键均可继续。每条消息开始时等待图标恢复为
默认图标，`(`/`)` 只影响当前及后续已累计消息的页尾图标。居中窗口仍一次显示完整文本并
在约 1.4 秒后自动继续。上方和下方对话等待期间每 100ms 轮转 palette `0xF9..0xFE`，
与原版图标闪烁节奏一致。

逐字揭示使用独立于模式化游戏逻辑时钟的 8ms 时钟量子，因此默认 24ms 字符间隔不会在同一
逻辑帧成对出现。`WOR16.FON` 不包含单字节 ASCII 字库；桌面端为可打印 ASCII 使用
Classic 同源的 Ka-Ping Yee 8x15 固定位图，不进行缩放或重采样。该字形每行按低位到高位
对应从左到右；原版资源中的 Big5 正文仍直接使用 16x15 字形。

`0x003B`、`0x003C`、`0x003D` 的 operand 2 表示对话发生在 RNG 动画期间。上方或
下方对话同时带头像时，原版会备份当前 RNG 画面供后续恢复；上方头像计算出的左上坐标
若为负数，需要钳制到零。RNG 对话标志置位后会保持到 `PAL_EndDialog`，中途值为零的
对话设置不会主动清除此标志。
